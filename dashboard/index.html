How the value is modelled

Implied value = TVL × category multiple × growth × age. The multiple is the median mcap/TVL of the tokenized protocols in the same category, computed from this snapshot (global median when a category has fewer than four tokenized peers). Growth is 1 + clamp(7-day TVL change, −40%, +80%) / 200. Age is 1 + min(years listed with no token, 6) × 0.06. No protocol name is hardcoded anywhere: the board is derived from the snapshot’s own figures, so re-running it on a new snapshot finds the next launches on its own.
